04 CURRICULUM & CAPABILITIES

WHAT WE LEARN

Pilar kompetensi keilmuan komputer yang dipelajari dan diasah oleh mahasiswa Informatika UNUGHA Angkatan 2026.

01

PROGRAMMING

+

Menguasai paradigma pemrograman modern, fondasi logika sintaks, modularitas, dan pemecahan masalah komputasi secara clean dan sistematis.

02

ALGORITHMS

+

Mempelajari struktur data fundamental, efisiensi kompleksitas waktu (Big-O), searching, sorting, graph, dan pemodelan matematis diskrit.

03

WEB DEVELOPMENT

+

Membangun platform aplikasi web responsif, arsitektur client-server modern, standar aksesibilitas WCAG, performa tinggi, dan API terintegrasi.

04

DATABASE

+

Normalisasi data, perancangan skema relasional SQL, integritas referensial, query optimization, serta manajemen basis data terdistribusi.

05

UI / UX

+

Menghadirkan pengalaman pengguna yang manusiawi, tipografi presisi, layout editorial, hirarki visual yang matang, dan prinsip ergonomi antarmuka.

06

ARTIFICIAL INTELLIGENCE

+

Fondasi penalaran cerdas, representasi pengetahuan, pembelajaran mesin (machine learning), pemrosesan data, dan etika implementasi teknologi cerdas.

07

COMPUTER SYSTEM

+

Arsitektur komputer, hierarki memori, representasi biner, instruksi CPU, interaksi sistem operasi, dan pemahaman level hardware ke software.

08

DIGITAL TECHNOLOGY

+

Ekosistem komputasi awan, kolaborasi open source , keamanan siber , dan pemanfaatan teknologi digital untuk masyarakat.
